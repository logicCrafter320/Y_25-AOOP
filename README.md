# Y_25-AOOP

## Java OOP Exercises

This repository contains five beginner-friendly Java programs covering classes, objects, constructors, methods, and basic encapsulation.

| No. | Folder | Concepts |
| --- | --- | --- |
| 1 | `01-Student` | Class, objects, fields, displaying object details |
| 2 | `02-Employee` | Parameterized constructor |
| 3 | `03-BankAccount` | Deposit and withdrawal methods, balance validation |
| 4 | `04-Rectangle` | Methods, area and perimeter calculations |
| 5 | `05-Book` | Parameterized constructor and object details |

## Requirements

- Java Development Kit (JDK) installed
- A terminal or command prompt

Check your Java installation:

```bash
java -version
javac -version
```

## Compile and run

Run each program from the repository's root directory.

### 1. Student

```bash
cd 01-Student
javac Student.java
java Student
cd ..
```

### 2. Employee

```bash
cd 02-Employee
javac Employee.java
java Employee
cd ..
```

### 3. BankAccount

```bash
cd 03-BankAccount
javac BankAccount.java
java BankAccount
cd ..
```

### 4. Rectangle

```bash
cd 04-Rectangle
javac Rectangle.java
java Rectangle
cd ..
```

### 5. Book

```bash
cd 05-Book
javac Book.java
java Book
cd ..
```

Each program is independent and has its own `main` method, so compile and run it from its corresponding folder.
